Analysis and classification model training and evaluation for the Bank Marketing datasets (bank-full and bank-additional-full) [1].

The code is provided in two Jupyter notebooks (including the output generated by the code).
Analysis.ipynb contains the data exploration, preparation, and analysis.
Model.ipynb contains the training and comparison of different models (each with different parameters) and an evaluation of the best models' performance.

[1] https://archive.ics.uci.edu/dataset/222/bank+marketing
